This opens the real timer inside This Quiet World, so your current scene, volume and other sleep settings stay in one place.

A sleep timer that fades instead of cutting off

When the timer reaches its final minute, This Quiet World gradually fades the nighttime ambience before muting it. There is no abrupt stop at the end of the countdown.

Works with the nighttime world

The timer belongs to the full This Quiet World experience, so you can use it with rain and the other nighttime ambience without running a separate timer page in the background. Set the timer, choose the world you want, then leave it alone.

Sunrise alarm stays separate

If you have the optional sunrise alarm armed, the sleep timer only fades the nighttime sound. The sunrise wake sound remains independent, so the timer does not quietly cancel your morning alarm.

What happens when the timer ends?

The current nighttime audio is muted after the final fade. You can reopen the timer at any time to change the duration or cancel it before it finishes.
