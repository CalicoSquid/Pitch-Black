Black Screen for Sleep

Turn the display into a quiet bedside surface: pure black when you want nothing at all, or black with a deliberately dim clock when you still need the time.

Tap or press any key to bring the controls back.

A black bedside screen without the video player

This page is intentionally simple. There is no looping black video, recommendation feed, advertising layer or bright playback chrome waiting to reappear. Once you start the screen, the page itself is black.

Want rain or a living night scene?

This Quiet World adds optional rain, storms, snow, embers, moonlight, fireflies and gentle nighttime sound. You can still keep it overwhelmingly dark, mute it completely, or use the dedicated rain page when that is all you need.

About keeping the screen awake

Supported browsers can request a screen wake lock while this page remains visible. Browsers and operating systems can still release it, so use your device settings when keeping the display on is essential.
